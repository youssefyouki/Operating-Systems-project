# Operating Systems project
Project Description: Multi-Level Reader-Writer Synchronization and Memory Management

Milestone 1: Inter-Process Communication and Synchronization
In this milestone, the project addresses the synchronization between two writer processes and two reader processes that share a memory segment. The synchronization scheme must handle two cases: priority for writers and priority for readers. In the writer-priority scenario, the system ensures that when a writer is ready to access the shared memory, it is granted exclusive access even if readers are active, preventing writer starvation. On the other hand, in the reader-priority case, multiple readers are allowed to concurrently access the memory as long as no writers are operating, ensuring faster read access and minimizing wait times for readers. However, when a writer is ready, it has exclusive access to the memory, blocking all readers until it finishes. The solution involves using semaphores and mutexes to control access: a reader count semaphore tracks the number of active readers, while a write semaphore ensures exclusive access for writers. The synchronization strategy guarantees that no writer or reader is blocked unfairly, balancing access between writers and readers based on the priority policy selected.

Milestone 2: Memory Management Simulator
The second milestone focuses on building a simple memory management simulator that supports both segmentation and paged memory allocation. The system assumes that processes have a fixed size, do not grow or shrink, and that no memory compaction is performed. The simulator will explore three core issues related to memory management:
⦁	Segmentation: Memory is divided into segments, each representing a logical part of the process such as code, data, and stack. However, segmentation can lead to external fragmentation, where memory is fragmented into small blocks that may not be large enough to allocate larger processes, reducing memory utilization.
⦁	Paging: Memory is divided into fixed-size pages, which helps eliminate external fragmentation but introduces internal fragmentation, where pages allocated to a process might not be fully utilized. This results in wasted memory within each page that is not being fully used by the process.
⦁	Fragmentation: Both segmentation and paging face fragmentation challenges. External fragmentation in segmentation reduces memory efficiency by creating gaps between allocated segments, while internal fragmentation in paging leads to inefficient use of memory within pages. The simulator will implement algorithms for memory allocation and deallocation, allowing for the observation of these fragmentation issues in a simplified environment.

Milestone 3: Multi-Level Generalized Reader-Writer System
The final milestone generalizes the Reader-Writer problem into a three-level system. At Level 1, three writers simultaneously write to a shared memory segment, where each writer may modify the content independently. At Level 2, a single reader reads from the first shared memory, processes the data, and writes the aggregated results into a second shared memory segment. At Level 3, three readers concurrently access the second shared memory, retrieving the processed data and using it for further analysis or display. This multi-level system requires effective synchronization across all levels to ensure that data flows smoothly and consistently. At each level, proper locking mechanisms are used to prevent data corruption: writers must have exclusive access to the shared memory, readers are allowed concurrent access, and the second-level reader must coordinate access to ensure no race conditions when reading and writing data. The challenge lies in managing synchronization across three stages of processing, ensuring data integrity and avoiding deadlocks while optimizing read/write efficiency across different levels.
